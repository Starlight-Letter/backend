# 별빛안부 백엔드

별빛안부의 API와 도메인 규칙을 구현하는 TypeScript 저장소입니다. 서비스 정책은 상위 작업 폴더의 `기능명세서_최종본.md`, 개발 순서는 `별빛안부_통합_구현계획서.md`를 따릅니다.

## 현재 구현

- 다리별 공개 질문 중 현재 시각에 적용되는 최신 질문 선택
- 새 질문이 없는 주에는 이전 질문 유지
- 다음 월요일 00:00 KST의 UTC 시각 계산

아직 HTTP API, 데이터베이스, 인증, AWS 인프라는 연결되지 않았습니다.

## 개발 명령

```bash
npm ci
npm test
npm run build
```
