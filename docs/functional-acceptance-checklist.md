# 별빛안부 기능 인수 점검표

기준일: 2026-10-07  
대상: React 프론트엔드 · Spring Boot API · PostgreSQL

## 판정 기준

- **통과**: 사용자 화면 또는 실제 HTTP 요청과 PostgreSQL 상태까지 확인했다.
- **실패**: 요구 결과와 다른 응답, 화면, 데이터가 확인됐다.
- **대기**: 실행 환경·운영 계정·외부 설정이 없어 아직 검증하지 못했다.
- 공개 전에는 **높음** 항목이 모두 통과해야 한다.

## 2. 회원 인증과 계정

| ID | 중요도 | 점검 항목 | 합격 기준 | 상태 |
|---|---|---|---|---|

| A-02 | 높음 | 중복 닉네임 | 활성 계정 닉네임은 중복 가입되지 않는다. | 대기 |

| A-04 | 높음 | 잘못된 로그인 | `INVALID_CREDENTIALS`로 처리되고 요청 제한이 적용된다. | 대기 |
| A-05 | 높음 | 복구 코드 | 코드로 비밀번호를 변경하면 기존 세션이 폐기된다. | 대기 |
| A-06 | 중간 | 비밀번호 변경 | 현재 비밀번호 검증 후 다른 기기 세션이 폐기된다. | 대기 |
| A-07 | 높음 | 회원 탈퇴 | 보관함은 삭제, 반응은 유지, 편지 표시 닉네임은 유지된다. | 대기 |

## 3. 편지 작성과 안전성

| ID | 중요도 | 점검 항목 | 합격 기준 | 상태 |
|---|---|---|---|---|
| L-01 | 높음 | 회원 작성 | 현재 질문·1~150자·테마 1~4 조건에서 공개 편지가 작성된다. | 통과 |
| L-02 | 높음 | 질문 변경 | 이전 질문 ID로 작성하면 `QUESTION_CHANGED`가 반환된다. | 대기 |
| L-03 | 높음 | 중복 제출 | 동일 키·동일 내용 재시도는 같은 ID와 `200`을 반환한다. | 대기 |
| L-04 | 높음 | 키 충돌 | 같은 키·다른 내용은 `IDEMPOTENCY_CONFLICT`로 거부된다. | 대기 |
| L-05 | 높음 | 기본 필터 | 욕설·광고·전화번호·이메일은 `CONTENT_REVISE`로 차단된다. | 대기 |
| L-06 | 높음 | 운영 규칙 | 활성 금칙어는 차단하고 비활성 규칙은 허용한다. | 대기 |
| L-07 | 높음 | Origin·본문 제한 | 허용되지 않은 Origin과 16KiB 초과 본문은 거부된다. | 대기 |
